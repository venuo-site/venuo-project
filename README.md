# Venuo — Plataforma de Geolocalização e Lazer

O **Venuo** é uma plataforma web responsiva (Mobile-First) focada na descoberta inteligente de opções de lazer, entretenimento, bares e eventos, inicialmente voltada para a Região Metropolitana de Goiânia. 

O projeto foi desenvolvido como uma Prova de Conceito (PoC) para a disciplina de **Projeto Integrador I** do curso de Análise e Desenvolvimento de Sistemas (turma 2026/1).

## O Diferencial Central: Descoberta em 3 Cliques

Diferente de soluções generalistas como o Google Maps ou redes sociais como o Instagram, o Venuo organiza informações de forma contextualizada para o momento real do usuário. Nosso foco é reduzir a fadiga de decisão através do princípio de **descoberta em no máximo 3 interações**:

1. **Clique 1:** Selecionar um filtro rápido na tela inicial (ex: "Bares").
2. **Clique 2:** Escolher o estabelecimento desejado no feed ordenado por proximidade física.
3. **Clique 3:** Executar a ação final no detalhe do local (como "Ver Rota" ou "Resgatar Cupom").

## Tecnologias e Ferramentas

Este repositório consolida todo o ciclo de vida do projeto [1-3]:

- **Design e UI/UX:** Prototipação responsiva de alta fidelidade desenhada inteiramente no **Figma**.
- **Desenvolvimento:** Implementação base desenvolvida em **HTML5, CSS3 e JavaScript**, garantindo leveza e acessibilidade.
- **Metodologia:** Desenvolvimento ágil estruturado em framework **Scrum**, planejado em 4 sprints.
